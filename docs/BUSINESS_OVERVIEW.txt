================================================================================
                    CHAT WALLET - BUSINESS OVERVIEW
================================================================================

EXECUTIVE SUMMARY
-----------------
Chat Wallet is a self-custodial crypto wallet that lets users manage USDC
through natural language conversation. Instead of navigating complex DeFi
interfaces, users simply chat: "Send $50 to Alice" or "Pay my AWS bill with
crypto."


================================================================================
                         WHAT IT DOES WITH USDC
================================================================================

CORE CAPABILITIES
-----------------
Feature                 | Description
------------------------|----------------------------------------------------
Multi-Chain Balances    | View USDC across Base, Arbitrum, Polygon in one place
Instant Transfers       | Send USDC via meta-transactions (gasless for users)
Gift Card Purchases     | Buy 1000+ gift cards (Amazon, Uber, Netflix) via Bitrefill
Bill Payments           | Pay AWS, subscriptions using USDC → gift card conversion
Merchant Payments       | Direct crypto to Porkbun, Namecheap, Mullvad VPN, Travala


TRANSACTION FLOW
----------------
User: "Send $20 to 0x123..."
        ↓
AI previews: Amount: $20, Fee: $0.04, Total: $20.04
        ↓
User confirms → Meta-transaction signed → Relayer executes → Done

KEY TECHNICAL DECISIONS
-----------------------
Component       | Choice                    | Rationale
----------------|---------------------------|----------------------------------
Wallet          | Self-custodial (HD)       | User controls keys, no liability
AI              | LangChain + Tool Calling  | Structured actions, not just chat
Database        | Supabase + RLS            | Secure multi-tenant, real-time
Encryption      | PBKDF2 + Fernet           | Industry-standard key derivation
Auth            | Cookie sessions + OAuth   | Persistent login, Gmail integration

================================================================================
                           REVENUE MODEL
================================================================================

TRANSACTION FEE STRUCTURE
-------------------------
Formula: $0.005 flat + 0.2% (max $3)

Examples:
- $100 transfer  → $0.005 + $0.20 = $0.205 fee
- $1000 transfer → $0.005 + $2.00 = $2.005 fee
- $5000 transfer → $3.00 fee (capped)


ADDITIONAL REVENUE STREAMS
--------------------------
• Gift card affiliate commissions (Bitrefill)
• Premium AI features (faster models, higher limits)
• Enterprise API access
